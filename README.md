
## 1. Start Game

```http
POST http://127.0.0.1:8080/api/start
```

Purpose: Initialize and create a new adventure.
Note: Scene index of the starting scene is 1

Request Body (JSON):

```json
{
  "player_name": "user_name" 
}
```

Response (JSON):

```json
{
  "status": "success",
  "adventure_id": adventure_id, \\ uuid4
  "player_name": player_name,
  "scene_data": scene_data
}
```

## 2. Player Action

```http
POST http://127.0.0.1:8080/api/action
```

Purpose: Send player choice (i.e. a, b, or c)

Request Body (JSON):

```json
{
  'player_choice': player_choice, \\ a, b, c
  'scene_idx': current_scene_idx, \\ previous_scene_idx + 1
  'adventure_id': adventure_id, 
  'player_name': player_name,
  'last_scene': last_scene
}
```

Response (JSON):

```json
{
    "next_scene": "The next scene that is generated by the llm",
    "choice_a": "Choice a that is generated by the llm",
    "choice_b": "Choice a that is generated by the llm",
    "choice_c": "Choice a that is generated by the llm",
    "end_game": false \\ Indicate whether this is the end of the adventure. Stop the adventure if end_game == true. Player action api will not generate next scene if the adventure with the adventure id is ended previously. 
}
```

## 3. Scene Data (The scene_data object that is used in the Start Game and Player Action responses)

```json
{
  "status": "success",
  "adventure_id": adventure_id,
  "player_name": player_name,
  "scene_data": scene_data
}
```
